# プロジェクト管理・自動Wiki・リンク図

## 設計

ローカル管理モード`serve --admin`で、Reactからプロジェクト作成、Windowsフォルダ選択、索引再作成、登録削除を実行する。通常serveは従来通り閲覧専用。管理APIは同一ローカルOriginと専用ヘッダーを検証し、ブラウザからの意図しない変更を拒否する。

0.3.0の画面では表示名・入力・出力親フォルダーを指定し、IDは自動生成する。CLIではIDも指定する。登録後に初回scanを実行。Wikiは原本Markdownの表示と解析したリンクから生成し、原本にページを書き戻さない。失敗時は作成した登録と索引を取り消す。既存IDは上書きしない。

削除は確認ダイアログを出し、原本を残して登録と該当プロジェクトの生成索引だけを削除する。再作成は原本の全ハッシュ照合とTantivy再構築。プロジェクト単位ロックを索引の外に置き、更新・再作成・削除の競合を防ぐ。閲覧にも共有ロックを使用する。CLI監視中のプロジェクトを削除する場合は先にwatchを停止する。

リンク図は初期200ノード、最大500ノード／1,000辺。選択文書があればその入出リンクの近傍を表示し、選択がなければ先頭文書群を表示する。省略の有無を表示する。全体10万ノードの一括描画は行わない。GraphologyとSigma.jsで描画し、クリックで文書を開く。

## 制約

管理APIはローカル利用専用。チーム管理権限、SSO、バックグラウンドジョブは対象外。安定世代の原子的公開は0.2.0で実装済み。大量索引生成中は管理操作の完了を待つ。Webだけではブラウザのフォルダ選択結果からサーバー上の絶対パスを取得できないため、Windows上のRust APIがネイティブ選択画面を開く。Windows以外ではパス入力を使用する。
