# Wiki閲覧バーの全文検索

1. Wiki・リンク図と履歴操作のバーに検索欄を置く。閲覧エリアを拡大した場合も同じ欄を使う。
2. 初期範囲はプロジェクト全体。元仕様書を選んだ場合は、選択中の元仕様書に切り替えられる。Rustは元仕様書ページと配下の要素パスを検索条件に追加し、絞り込んだ後にページ分けする。既存索引のパスを使う。
3. 検索結果は左枠だけを更新する。中央と右側は閲覧中のページを保持し、結果を選択した時点で連動する。結果一覧の見出しに実行済みの範囲を表示する。
4. 履歴に検索語・実行済みの範囲・選択ページを保存する。「戻る」「進む」で復元し、本文は必要時に再取得する。
5. 範囲違いの同一検索語、ページ分け、全画面時の検索と既存ページの保持、履歴復元を確認する。Rust・WebテストとWindows版ビルドを実行する。

## 確認結果

合成Wikiで、閲覧エリアを拡大したまま検索し、範囲の切替、中央の閲覧状態の保持、結果からの移動、同じ検索語で範囲だけが違う履歴の復元を確認した。Rustの回帰テストで、範囲をページ分け前に適用し、別の元仕様書が混ざらないことを確認した。
