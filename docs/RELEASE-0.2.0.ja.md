# 0.2.0 検証結果（2026-11-01）

## 完了範囲

ローカルDesktop／loopback Web版の残機能を実装した。ネットワーク公開・IIS・SSO・外部自動更新配信はユーザー指示により対象外。コード署名証明書は未準備で配布物は未署名。

## 機能と安全性

- Windows Rust Core 22件、HTTP API 5件、Service 1件、Desktop 1件、React 8件のテスト。fmt・clippy・Rust/Web/Desktop releaseビルド。
- 公開直前の失敗と子プロセス終了（終了コード77）を注入し、旧本文・旧検索結果の一致と次回scanでの復帰を確認。
- 旧メタデータに対する対象パス更新を全体移行へ切り替え、別名・見出し・検索索引の取り残しを防ぐ回帰試験。
- 文書／検索／参照元の追加取得、503文書の参照元、グローバル5,000リンク外の個別解決、無効なページ条件を試験。
- 別名、見出し欠如、空HTMLアンカー、離れた文字列の誤一致防止、原本不変、監視での実変更・停止、バックアップ・復元を試験。
- HTMLを実行せずに表・安全なアンカーを表示するReact回帰試験。DesktopのIPCとWebの管理POST保護ヘッダーを検証。
- WindowsのNSISインストール→実機起動→実文書表示→監視開始／停止→集約図→終了→アンインストールを確認。アンインストーラーは終了コード0、アプリexeとアンインストール登録の消去を確認。検証用索引と原本は保持。
- 本番Webを一時的に起動し、HTML 200、検索ページ、集約図APIの成功と待受127.0.0.1だけであることを確認後、停止。

## 指定実文書

実文書334件、114,629,651バイト。初回索引9.19秒、無変更走査7.94ms、検索P95 11.22ms、Backlinks P95 2.77ms。

タイトル先頭32文字を使った簡易試験では、50クエリすべてで対象文書が上位50件に入った。これは専門家による関連性ラベル付き検索評価の代用ではない。リンク33,123件、リンク先なし4件、見出しなし0件。原本MD全件のパスと内容の集約ハッシュが評価前後で一致した。本文・ファイル名を性能報告へ含めず、原本をGitへ保存していない。

[実文書の集計結果](benchmarks/real-corpus.json)。提供データは334件であり、実文書10万件の達成は主張しない。

## 合成8KiB文書

Windows release、1文書8,192バイトの生成段落。全件に共通語を含む合成文書で、実文書とは区別する。

|ファイル数|初回索引|反復検索P95|未キャッシュ3語の最大|Backlinks P95|対象更新P95|サンプル最大ワーキングセット|
|---:|---:|---:|---:|---:|---:|---:|
|10,000|11.11秒|6.70ms|25.25ms|4.82ms|846.14ms|0.21GiB|
|50,000|63.89秒|5.31ms|84.91ms|3.85ms|1627.48ms|0.50GiB|
|100,000|136.78秒|6.98ms|259.34ms|4.99ms|1493.42ms|1.42GiB|

- 反復検索は同じ3語を100回検索し、Reader／結果キャッシュを含む。初回3語の時間もJSONへ保存して区別した。
- 対象更新は10回、P95は少数試行の最大値になる。raw各試行をJSONへ保存した。250msの監視待ち・イベント配送・IPC／HTTP・画面描画は含まない。
- **初回10万件5分以内、反復検索100ms、Backlinks 30msは測定範囲で達成。未キャッシュ共通語検索の100ms、対象差分1秒は一部で未達。** 全ての条件で目標達成したとは扱わない。
- メモリは100ms間隔でプロセスのワーキングセットを取得したサンプル最大値。厳密な全瞬間のピーク値やプライベートバイトではない。
- 索引容量はファイルの論理サイズ合計。世代間で共有するハードリンクは重複して数える。
- 通常のWindows利用環境で測定し、OSキャッシュ、他プロセス、ストレージ状態の影響を含む。独立した負荷試験設備での再現性保証ではない。

再現: releaseで`cargo build -p hub-core --release --example benchmark`後、`scripts/benchmark-matrix.ps1`。raw結果は[1万件](benchmarks/synthetic-10000-8192.json)、[5万件](benchmarks/synthetic-50000-8192.json)、[10万件](benchmarks/synthetic-100000-8192.json)。

## 運用上の制約

画面内の複数要求／複数ページをまたぐ世代固定は未提供。監視反映後は表示を更新する。差分は同期mergeを抑えるため、長期運用で容量や検索時間が増えた場合は「再作成」で最適化する。画像・添付・Mermaidコードブロックの図化・横断検索・AI/MCPは将来機能。詳細は[運用](OPERATIONS.ja.md)と[制約一覧](../TODOS.md)。
