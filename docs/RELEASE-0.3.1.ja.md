# 0.3.1 新規作成時の保存先案内

既存プロジェクト閲覧中の新規作成で、選択する親フォルダーと実際の専用保存先が分かりにくかったため、表示と切替を修正した。

- 新規作成は「出力の親フォルダー」を選び、「今回、新しく作成する保存先」を別枠で表示する。
- 前回の親フォルダーは候補であることと、変更可能であることを明記する。
- 既存を開く場合は「project.jsonがある専用フォルダー」を指定する説明へ変更する。
- 新規／既存を開くフォームの表示中は、閲覧中プロジェクトの保存先設定と旧出力一覧を隠し、再作成・削除を無効にする。
- 新規作成を開き直すと名前・入力を初期化し、新しいIDを割り当てる。

## 実画面での検証

テスト設定と合成文書だけを使用して、以下を確認した。

1. 既存閲覧→新規作成：親フォルダーのラベル、前回候補の説明、生成先プレビューを表示。既存の保存先設定は非表示。
2. 入力後にキャンセル：元のプロジェクトの選択・閲覧を維持し、保存先設定を再表示。
3. 新規を開き直す：前回の下書き名・入力を引き継がず、別の生成先を表示。
4. 同じ親で新規作成：新しいWikiへ切替。旧プロジェクトと異なるID／専用出力に保存される。
5. 原本2件・親フォルダーの既存ファイル2件のSHA-256が開始前と一致。

React 11件とTypeScript／本番ビルドを通過し、Windows単体exeとNSISの0.3.1を生成。Rustの保存ロジックは変更していない。CIの結果は該当コミットのGitHub Actionsを参照。
