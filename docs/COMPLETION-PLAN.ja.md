# ローカル版 残作業の完了計画（2026-11-01）

ユーザーは既存の残作業の実装継続を承認し、実文書の評価先を指定した。その後「ネットワークに公開しない」と指定したため、ローカルDesktop／loopback Webへ範囲を確定した。

## 実装と検証

- [x] 原子的公開：SQLiteの本文・リンク・検索世代の参照先を同時commitする。検索世代完成前に公開しない。旧世代閲覧と子プロセス終了で復旧を試験。
- [x] 文書・検索・参照元・出リンクをページ取得。文書503件の参照元と本文リンクの個別解決を試験。
- [x] Desktopのプロジェクト別notify workerを開始・停止し、状態を表示。原本更新は作業用サンプルで試験し、実文書は変更しない。
- [x] 別名・見出し・空HTMLアンカー、孤立／同名集計、集約図、Markdown表表示。
- [x] 16文書バッチ、位置情報付き文字検索、Reader／結果キャッシュ、不変segmentの共有、差分中のmerge分離。
- [x] バックアップと新しい保存先への復元。元ファイル不変・復元後検索を試験。
- [x] ローカルWeb配信を起動してページ・新API・127.0.0.1 bindを確認後停止。
- [x] 実文書334件を読み取り専用で評価。合成8KiB文書を1万／5万／10万件で測定。区別して結果を保存。
- [x] Windows配布ビルド、インストール・実機起動・アンインストール。

## 完了の外部条件

コード署名は所有者の証明書が未準備で、未署名のまま提供する。ネットワーク公開と自動更新配信はユーザー指示により実施しない。性能の測定結果と既知の制約は[0.2.0検証結果](RELEASE-0.2.0.ja.md)を参照。
